# Fund Returns Daily

Daily fund return dashboard built from KFR Partner API price JSON, `mapping.xlsx`,
and `Hana_EMP.xlsx`.

## Files

- `download_fund_prices_api.py`: Downloads the daily `prices_YYYY-MM-DD.json` snapshot.
- `data/kfr/prices_legacy_history.json.gz`: One-time API-shaped conversion of pre-cutover history.
- `build_fund_dashboard.py`: Builds the standalone HTML dashboard.
- `docs/index.html`: GitHub Pages entry point generated by the build script.
- `mapping.xlsx`: Fund name/type/manager/launch-date mapping.
- `Hana_EMP.xlsx`: Manually maintained EMP cumulative return data.

## GitHub Actions setup

Create these repository secrets before running the scheduled workflow:

- `KFR_APP_KEY_ID`
- `KFR_APP_KEY_SECRET`

The workflow runs at 07:30 KST and retries at 10:00 and 14:00 KST on Korean
business days. Each run validates the target-date API JSON first. It downloads
again only when the file is missing or invalid, then rebuilds the HTML, commits
the updated files, and deploys `docs/index.html` to GitHub Pages. This also lets
the later runs recover from an earlier build or deployment failure without
downloading a duplicate valid file.

Pushes that update `mapping.xlsx`, `Hana_EMP.xlsx`, or the dashboard scripts
rebuild and redeploy the page without downloading raw data.

In repository settings, set GitHub Pages to use **GitHub Actions** as the source.
